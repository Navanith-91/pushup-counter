# 🏋️ AI Pushup Counter

An AI-powered Pushup Counter web application that tracks and counts pushups using computer vision and user tracking.

## 🚀 Features

- 🎯 Real-time pushup counting
- 🧠 AI-based posture tracking
- 📷 Camera integration
- 📊 User tracking system
- 🌐 Web-based interface
- ⚡ Fast and responsive UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- AI / Computer Vision
- GitHub Pages / Vercel Deployment
